# Doris Chacon Resume

This repository contains two resume versions for different review contexts.

## Resume versions

### Visual version

Files:

- `index.html`
- `styles.css`
- `downloads/Doris_Chacon_Resume_Visual_2026.pdf`

Use this version for:

- Direct emails to recruiters
- Networking
- Portfolio presentation
- Client introductions
- Applications where a person will review the document directly

Public URL: https://dorischacon.github.io/Designer-profile/

### ATS version

Files:

- `ats.html`
- `ats.css`
- `downloads/Doris_Chacon_Resume_ATS_2026.pdf`

Use this version for:

- Applicant tracking systems
- Job application forms
- Greenhouse
- Workable
- Lever
- Workday
- Other platforms that automatically parse an uploaded resume

Public URL: https://dorischacon.github.io/Designer-profile/ats.html

## Downloads

- Visual PDF: https://dorischacon.github.io/Designer-profile/downloads/Doris_Chacon_Resume_Visual_2026.pdf
- ATS PDF: https://dorischacon.github.io/Designer-profile/downloads/Doris_Chacon_Resume_ATS_2026.pdf

The ATS PDF is generated in `downloads/`. The visual PDF should be created from the published visual HTML using Chrome Print Preview with Letter paper, 100% scale, margins set to None, headers and footers off, and background graphics on. This preserves the approved two-column visual layout when the local headless exporter adds an extra blank page.
